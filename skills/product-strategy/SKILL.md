# Product Strategy（产品 / 商业）

## 何时触发

关键词命中即触发：产品、商业、PMF、商业模式、增长、营销、战略、客户、用户、市场、竞争、定位、护城河、单位经济、LTV、CAC、创业、YC、融资。

## 速记 6 条

1. **PMF 第一**：没达成 PMF 别想规模增长
2. **单位经济**：LTV / CAC > 3 才健康
3. **增长飞轮**：飞轮要形成闭环
4. **10x 更好**：要么 10x 优于现有方案，要么不同维度
5. **护城河**：网络效应 / 规模经济 / 品牌 / 切换成本
6. **市场分析**：先 TAM / SAM / SOM 再定策略

## 自检清单

- [ ] 是否验证 PMF？
- [ ] 单位经济是否健康（LTV/CAC）？
- [ ] 是否有清晰增长飞轮？
- [ ] 是否 10x 优于现状？
- [ ] 护城河是什么？
- [ ] TAM/SAM/SOM 是否清楚？
