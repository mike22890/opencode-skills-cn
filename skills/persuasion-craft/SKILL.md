# Persuasion Craft（表达 / 说服）

## 何时触发

关键词命中即触发：表达、说服、演讲、讲故事、影响力、谈判、销售、文案、TED、演示、推介、路演、pitch、引导、影响。

## 速记 6 条

1. **故事 > 数据**：人记故事不记数字
2. **黄金圈**：Why → How → What
3. **Hook-Story-Offer**：钩子 → 故事 → 行动
4. **互惠 / 稀缺 / 权威 / 一致 / 喜好 / 共识**（6 大法则）
5. **校准问题 / 镜像 / 标签**（Voss 谈判）
6. **减法优于加法**：删废话

## 自检清单

- [ ] 是否有钩子（前 30 秒）？
- [ ] 故事结构是否清晰？
- [ ] 是否调用影响力法则（合道德）？
- [ ] 是否有清晰 CTA？
- [ ] 是否减法（删废话）？
- [ ] 是否给对方留思考空间？
