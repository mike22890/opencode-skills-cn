# 亲密场景文学技巧（精简版）

> ✅ 教写作技巧 + 大师分析 ❌ 不生成 explicit content

## 大师风格

| 派别 | 大师 | 核心 |
|---|---|---|
| 暗示 | 张爱玲/杜拉斯/川端 | 心理>动作/物件暗示/留白 |
| 感官 | 劳伦斯/谷崎/沈从文 | 身体觉醒/自然主义/恶之美 |
| 心理 | 渡边/纳博科夫/三岛 | 死亡情爱/美学殉道 |
| 古典 | 曹雪芹/兰陵笑笑生 | 情感性心理/物质细节 |

## 5 大原则

1. **暗示>直白**：多层暗示（动作/物件/环境/时间）
2. **感官≥3维**：视/听/嗅/触/味，每感官做层次
3. **情感>物理**：欲望/恐惧/撕裂/超越/告别
4. **节制>放纵**：杜拉斯整本《情人》只有几个场景
5. **心理4阶段**：期待→沉浸→余韵→反刍

## 身体描写 6 层次

```
L1 动作（禁）→ L2 +感官 → L3 +心理 → L4 +暗示 → L5 +隐喻 → L6 +哲学（大师层）
```

## 身体细节 8 要素

皮肤（张爱玲"绸缎"/劳伦斯"火焰"）/ 体温（升温/降温/季节）/ 汗（劳伦斯"第二层皮肤"）/ 呼吸（浅/深/屏/叹）/ 心跳（加速/同步/失序）/ 声音（呼吸/沉默/名字）/ 表情（张爱玲眉眼/杜拉斯阴影/川端睡颜）/ 姿态（缠绕=纠缠/远离=距离/翻转=权力）

## 禁忌情感 5 类

| 禁忌 | 大师作品 | 核心 |
|---|---|---|
| 母子/亲缘 | 《雷雨》《儿子与情人》《俄狄浦斯》 | 被动/扭曲/无法分离/毁灭 |
| 师生 | 《简·爱》《查泰莱》《失乐园》《睡美人》 | 不对等/崇拜/代价 |
| 跨阶级 | 《茶花女》《盖茨比》《长恨歌》《倾城之恋》 | 阶层是身体/反差/瞬间 |
| 婚外情 | 《安娜》《包法利》《失乐园》《红玫瑰》 | 日常背叛/两难/代价 |
| 权力不对等 | 《洛丽塔》《查泰莱》《金瓶梅》 | 明示/能动性/不美化 |

## 结局 7 种

反转（O.Henry）/ 戛然而止（海明威）/ 余韵（沈从文）/ 主题回响（托尔斯泰）/ 升华（雨果）/ 戛灭（劳伦斯/三岛）/ 循环（马尔克斯/曹雪芹）/ **复合**（大师最爱叠加）

## BDSM / 暴力 / 公开 / 姿势 / 羞辱

| 题材 | 大师 | 要点 |
|---|---|---|
| BDSM | 萨德/巴塔耶/卡特/谷崎 | 哲学化/理论/女性主义颠覆 |
| 暴力+情色 | 萨德/卡特/劳伦斯/渡边 | 探索人性/不美化 |
| 公开场合 | 薄伽丘/佩特罗尼乌斯/劳伦斯 | 剧场化/暴露/权力 |
| 姿势多样性 | 爱经/素女经/芳香园/紫式部 | 文学化/情感语言/创新命名 |
| 辱骂/羞辱 | 萨德/卡特/源氏物语/红楼梦 | 权力侵入/转化/节制 |

## 写作者伦理底线

```
❌ 不美化性侵/强奸 ❌ 不美化儿童性化 ❌ 不把非自愿包装成自愿
❌ 不把权力不对等包装成浪漫 ❌ 不用"文学"为剥削辩护
```
