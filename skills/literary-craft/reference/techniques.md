# 写作核心技巧（精简版）

## 1. 暗示>直白（Show Don't Tell）

```
❌ 她很悲伤。
✅ 她把脸转向窗外，窗外什么都没有。

❌ 他很愤怒。
✅ 他把杯子放在桌上，没摔，但放得很重。
```

**暗示清单**：情绪→动作代替形容词 / 氛围→环境 / 关系→距离朝向 / 心理→身体反应

## 2. 感官细节（≥3维）

每段至少 3 感官：

| 感官 | 用什么 |
|---|---|
| 视觉 | 光影/颜色/形状/动态 |
| 听觉 | 声音质地/节奏/沉默 |
| 嗅觉 | 气味/季节/记忆 |
| 触觉 | 温度/质地/压力 |
| 味觉 | 食物/饮料/口腔 |

**混搭**：咖啡的苦在舌尖 + 雨打玻璃 + 手指划过木头的凉

## 3. 节奏控制

- 长段叙事：铺陈/描写/心理
- 短句冲击：动作/转折/关键
- 单句段：强调/留白
- 对话：加速
- 留白：重要时刻前后空行

**对比**：
```
❌ 均匀段落（无变化）
✅ 有节奏：她走进房间。他坐在窗边，看起来很累。她走过去，在他身边坐下。他没说话。她也没说话。
```

## 4. 留白即力量

- 重要对话前后 / 情感高潮 / 转折前 / 结尾回响
- 形式：空一行 / 单句成段 / 省略号（节制）
- 不滥用（稀释）

## 5. 对话即人

- 每个角色说话方式不同（年龄/职业/教育/地域/性格）
- 不用对话解释剧情
- 潜台词：嘴上≠心里
- 沉默=没说比说的更重要

**5 种对话**：推进剧情 / 展现性格 / 制造张力 / 潜台词 / 沉默

## 6. 人物塑造 4 维度

| 维度 | 内容 |
|---|---|
| 外在 | 衣着/姿态/动作习惯 |
| 语言 | 说话方式/词汇/节奏 |
| 心理 | 动机/恐惧/欲望 |
| 关系 | 与他人关系网 |

**速写**：不要全说 / 从动作见人 / 从矛盾见人 / 从细节见人

## 7. 场景构建 5 元素

空间/时间/氛围/物件/变化

**切换**：动作过渡 / 时间跳跃 / 感官切换 / 不用"话说"

## 8. 情节节奏

**起承转合**（中式）/ **三幕剧**（西式 25/50/25）

**钩子**：开头 100 字必须有 / 每章结尾必须有 / 不等于悬念剧

## 9. 视角

- 我：强代入但受限
- 他/她：全知或限知
- 你：罕见强侵入
- 多视角：每章换 / 同事件多视角

## 10. 结尾 5 种有力

1. 呼应开头
2. 戛然而止
3. 反讽反转
4. 余韵悠长
5. 主题回响

**反例**："从此幸福" / "终于明白" / "也许这就是人生" / 解释一切

## 11. 反 AI 文学味 10 条

1. 不"在很久以前"开头
2. 不"我的心情久久不能平静"
3. 不"从此幸福"
4. 不堆砌华丽形容词
5. 不滥用感叹号/省略号
6. 不解释所有隐喻
7. 不"那一刻，我终于明白了"
8. 不强行升华
9. 不"愿你走出半生"
10. 不说教

## 12. 编辑 4 步

1. 删 30% 字
2. 把"很好"换具体细节
3. 读出声听节奏
4. 隔夜再看

## 13. 速查卡

```
暗示>直白 / 感官≥3维 / 节奏有起伏 / 留白关键处 / 对话即人 / 结尾有力 / 不烂尾不解释
```
